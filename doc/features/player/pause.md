# Pause

## Requirements
* The game starts unpaused.
* Escape toggles between playing and paused states.
* Pausing displays a pause menu.
* Resuming removes the pause menu.

## User scenarios
### 1. The game starts in the playing state
### 2. Pressing Escape pauses the game
### 3. Pressing Escape twice resumes the game
### 4. Pausing spawns the pause menu
### 5. Resuming despawns the pause menu
