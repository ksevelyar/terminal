# Viewpoints

## Requirements
* Players can select the previous and next map viewpoints.
* Viewpoint navigation wraps at both ends of the viewpoint list.
* Selecting a viewpoint resets player position and look direction.
* Restarting a map selects its first viewpoint.

## User scenarios
### 1. Comma selects the previous viewpoint and period selects the next
### 2. Viewpoint selection wraps in both directions
### 3. Switching viewpoints resets player position and look direction
### 4. Restarting selects the first viewpoint
