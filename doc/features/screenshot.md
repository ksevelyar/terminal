# Screenshots

## Requirements
* Screenshots capture the selected map viewpoint.
* Screenshots are named `<version>-<scenario>-<viewpoint>.png`.
* Selecting an unknown viewpoint reports the viewpoints available for that map.
* Collision inspection screenshots hide weapons and show inspection visuals.

## User scenarios
### 1. The screenshot app captures a map01 frame
### 2. The screenshot app captures the intro dunes viewpoint by name
### 3. The screenshot app reports available viewpoints for an unknown name
### 4. A collider screenshot hides weapons and enables physics gizmos
